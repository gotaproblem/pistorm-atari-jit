# Games - OPTIONAL, run with REGRESS_GAMES=1 tools/regress/run.sh (with the
# rest) or tools/regress/run.sh games (alone). See run_games in run.sh.
#
#   name | section | rom | image | seconds | extra     one game
#   scan | section | rom | dir   | seconds | extra     every .st/.msa in dir
#                                      (named g<tos>-<title>); of a set,
#                                      only "(Disk 1 of N)"
#
# section is the psctrl.cfg machine the games boot on; its hdd/acsi/fdd/
# hostfs/ide lines are dropped and the game goes in A:. rom is a file in
# [psctrl] rom_path and replaces the section's rom. extra (- = none) is
# `;`-separated cfg lines, each replacing the section's line(s) for that
# key - [regression] is an STE with the ST-RAM cache on for the tests
# above, and games run on a plain ST without it. Paths are relative to
# the repo. One boot per game: ~40 images take ~40 minutes per TOS line.
