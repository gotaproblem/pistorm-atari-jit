# Regression register - one guest test per line, run by tools/regress/run.sh.
#
#   name | cfg section | hdd image | start | extra cfg | seconds | checks | what it guards
#
# The section is copied out of ../configs/psctrl.cfg, so each test runs on
# the same machine settings you use by hand; then
#   hdd image  - (the section's own drives) or an image, relative to the
#              repo. With start - it replaces the section's hdd lines and
#              must boot and AUTO-start the test itself; with a start it
#              goes on ACSI ID 0 (C:) in place of the section's hdd and
#              acsi images.
#   start      - or `;`-separated directives that build the boot floppy A:
#              (the section's fdd lines are dropped; EmuTOS boots from A:):
#                auto PATH [ARGS]  A:\AUTO\LAUNCH.PRG runs PATH (TOS programs)
#                desk PATH         the desktop autostarts PATH (GEM programs)
#                acc NAME ARG      guest/NAME.PRG as A:\NAME.ACC, ARG in A:\NAME.INF
#              see make_start_floppy in run.sh.
#   extra cfg  - or `;`-separated cfg lines appended after the section
#              (the last value wins), e.g. to run the governed 68000.
# A test PASSES when the guest runs the whole time with no EmuTOS "Panic:"
# and the emulator neither crashes nor exits, and every check in the checks
# column holds (- = none):
#   vbl=50  gov>=7900  noov  snd  shmcal      - see host_checks in run.sh.
# Tests run with PISTORM_IPL_STATS=1 PISTORM_GOV_REPORT=1
# PISTORM_SHM_DEBUG=1 PISTORM_DMASND_DEBUG=2 for those reports (one line a
# second or less each). gov needs the 68000 governed (JIT off, cpu_speed
# set); shmcal needs native_hdmi and the governed 68000.
#

Run with the BBaN DISCONNECTED - its ACSI ID 1 answers a 1-sector read with 11 sectors and TOS 3.06's 255-sector limit lets them over $2908
ide-acsi | games | -                                | - | - | 60 | -  | TOS 2.06 + IDE images + a REAL ACSI board on the bus (connect it, any card): TOS probes IDE first (IDENTIFY, READ SECTORS x1) and the model must drop INTRQ after the last PIO data-in sector, or GPIP5 stays low, the ACSI probe reads every status at once ($FF), the board's read lands in live RAM and TOS runs away to $03000002 (fixed 8326bd3, was Falcon-only). Needs the section to boot TOS 2.06 with its IDE images
