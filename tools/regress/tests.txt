# Regression register - one guest test per line, run by tools/regress/run.sh.
#
#   name | cfg section | hdd image (AUTO-starts the test, - = the section's own drives) | seconds | checks | what it guards
#
# The section is copied out of ../configs/psctrl.cfg as-is, so each test
# runs on the same machine settings you use by hand; only the hdd line is
# swapped for the test image. A test PASSES when the guest runs the whole
# time with no EmuTOS "Panic:" and the emulator neither crashes nor exits,
# and every check in the checks column holds (- = none):
#   vbl=50  gov>=7900  noov  snd  shmcal      - see host_checks in run.sh.
# Tests run with PISTORM_IPL_STATS=1 PISTORM_GOV_REPORT=1
# PISTORM_SHM_DEBUG=1 PISTORM_DMASND_DEBUG=2 for those reports (one line a
# second or less each). gov needs the section to be governed (JIT off,
# cpu_speed set); shmcal needs native_hdmi and the governed 68000.
#
# Test image: a copy of a bootable C: image with the program in C:\AUTO\
# (EmuTOS runs C:\AUTO\*.PRG at boot - rename .TOS to .PRG). Anything the
# program loads by relative name goes in C:\ (root) beside AUTO.
#
